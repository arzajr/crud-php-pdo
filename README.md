# Mini Retos PHP

## Descripción

Mini proyecto CRUD desarrollado con PHP, MySQL y PDO.

El proyecto permite:
- Crear ideas
- Consultar ideas
- Modificar ideas
- Eliminar ideas
- Validar datos
- Evitar duplicados
- Mostrar mensajes mediante sesiones

## Tecnologías

- PHP
- Apache
- MySQL
- PDO
- HTML
- Bootstrap

## Requisitos

- XAMPP
- PHP
- Apache
- MySQL

## Instalación

### 1. Clonar el repositorio

git clone ...

### 2. Copiar el proyecto

Colocar la carpeta dentro de:

htdocs/

### 3. Configurar MySQL

Puerto utilizado: 3308

Crear la base de datos y tabla ejecutando:

database.sql

### 4. Configurar la conexión

Editar db.php:

host: localhost
port: 3308
database: php_pruebas
user: root

### 5. Iniciar XAMPP

Iniciar:
- Apache
- MySQL

### 6. Acceder al proyecto

http://localhost/crud-php-pdo/
